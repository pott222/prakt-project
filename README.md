# Портфолио Юрия

Небольшой адаптивный сайт-портфолио. Разметка, стили и интерактивность лежат отдельно, а Gulp собирает их в файлы, которые подключены на странице.

## Запуск

1. Установите Node.js.
2. В PowerShell из папки проекта один раз выполните `npm.cmd install`.
3. Выполните `npm.cmd run dev`, чтобы собрать файлы, автоматически пересобирать их после изменений и запустить локальный сервер.
4. Откройте в браузере `http://127.0.0.1:3000/`. Остановить сервер можно сочетанием `Ctrl+C`.

Для проверки сетевого интерфейса в CMD выполните `ping 127.0.0.1`. Команда `ping` проверяет IP-адрес, а не URL сайта; доступность страницы проверяйте в браузере по адресу выше.

Для однократной сборки выполните `npm.cmd run build`.

## Где редактировать

- `index.html` — текст, ссылки, разделы и карточки проектов. Скопируйте существующий блок проекта `<article class="project">...</article>`, чтобы добавить карточку.
- `src/scss/_variables.scss` — цвета и ширина контента; остальные SCSS-файлы разделены на общие стили, раскладку, компоненты и оформление страницы.
- `src/js/main.js` — интерактивность страницы.
- `src/img/` — изображения. Добавьте файл сюда и укажите его путь в HTML, например `img/my-project.jpg`.
- `gulpfile.js` — правила сборки и наблюдения за исходными файлами.

Папки `css/`, `js/` и `img/` в корне — результат сборки. Не редактируйте их вручную: Gulp пересоздаёт их из `src/`.

## Добавление страниц

Создайте HTML-файл в корне и подключите в нём `css/main.css` и `js/main.js`, как в `index.html`. Стили и скрипты для всех страниц добавляйте в соответствующие исходные файлы в `src/`.
